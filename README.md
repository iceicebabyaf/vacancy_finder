# Поиск предложений работы среди круга знакомых
Данное приложение позволяет вам искать релевантные предложения работы, согласно вашему профилю пользователя, среди вашего круга общения.
## Принцип работы
Приложение анализирует посты ВК людей на расстоянии 2 в вашем графе закомств (друзья и друзья друзей), с помощью методов машинного обучения анализирует их, сопоставляет с вашим профилем и возвращает потенциально интересные предложения
## Почему это полезно
Обход графа связей с глубиной всего лишь 2 может предложить вам огромное количество вакансий и подработок, на которые легко откликнуться, написав знакомому человеку, либо, обратившись к нему через вашего друга. В это же время поиск предложений о работе через знакомые сервисы может продолжаться длительное время без особого успеха
## Установка и запуск
1. Клонируйте репозиторий `git clone https://github.com/iceicebabyaf/vacancy_finder.git`
2. Создайте виртуальную среду Python `python -m venv venv` и активируйте её: для Windows `venv/scripts/activate`, для Linux/MacOS `source venv/bin/activate`
3. Установите зависимости `pip installl -r requirements.txt`
4. Запустите приложение python main.py --profile <profile> --url <url>, указав аргументы `--profile` -- описание вашего профиля пользователя, `--url` -- адрес вашей страницы ВК
5. Доступны аргументы `--model_type` и `model_threshold` для выбора модели, производящий анализ вашего профиля и вакансий и ее порога.
